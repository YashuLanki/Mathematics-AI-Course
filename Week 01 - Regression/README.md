# Fish Weight Regression

AIT 525 assignment — predicting fish weight from physical measurements using linear regression.

Implements and compares two models on the [Fish Market dataset](https://www.kaggle.com/datasets/vipullrathod/fish-market): a closed-form `LinearRegression` baseline and a gradient-descent-optimized `SGDRegressor`, evaluated with MSE and R².

- [`Fish_Weight_Regression.ipynb`](./Fish_Weight_Regression.ipynb) — the full notebook: dataset exploration, mathematical model design, implementation, performance evaluation, and real-world applications.
- [`Assignment.docx`](./Assignment.docx) — original assignment instructions.
- [`script.md`](./script.md) — narration script for the video presentation.
