# Dataset: Two NLP Research Papers

Source documents for the document similarity assignment — chosen because the second paper directly builds on the architecture introduced in the first, making the similarity analysis meaningful rather than arbitrary.

- **"Attention Is All You Need"** — Vaswani et al., 2017. [arXiv:1706.03762](https://arxiv.org/abs/1706.03762)
- **"BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding"** — Devlin et al., 2018. [arXiv:1810.04805](https://arxiv.org/abs/1810.04805)

## Files

- `Attention_Is_All_You_Need.pdf`
- `BERT.pdf`

Both are arXiv preprints under arXiv's default non-exclusive distribution license — the authors retain copyright. `*.pdf` is gitignored repo-wide, with an exception carved out for these two files so they're tracked here.
