# Matrix and Vector Operations

AIT 525 assignment — applying basic linear algebra to a real dataset.

Demonstrates matrix addition, subtraction, multiplication, and dot products (using NumPy) on the [UCI Adult dataset](https://archive.ics.uci.edu/dataset/2/adult), with an explanation of each operation's significance in AI/ML data analysis.

- [`Matrix_Vector_Operations.ipynb`](./Matrix_Vector_Operations.ipynb) — the full notebook: all four parts (basic operations, transpose/inverse, rank, linear independence) with code, explanations, and a References section.
- [`adult_data/`](./adult_data) — the UCI Adult (Census Income) dataset files.
- `Matrices Assignment.docx` — original assignment instructions (not tracked in git).
- `script.md` — narration script for the video presentation (not tracked in git).
