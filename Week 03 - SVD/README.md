# SVD and PCA for Dimensionality Reduction

AIT 525 assignment — comparing SVD and PCA for dimensionality reduction.

Applies Singular Value Decomposition and Principal Component Analysis to the [International Graduates Employment dataset](https://www.kaggle.com/datasets/quackquackrp/international-graduates-employment-dataset), exploring how graduates' education level and field of study relate to employment outcomes, and comparing the two techniques' trade-offs.

- [`SVD_PCA_Dimensionality_Reduction.ipynb`](./SVD_PCA_Dimensionality_Reduction.ipynb) — the full notebook: dataset overview, SVD, PCA, and a comparison of both methods.
- [`graduates_data/`](./graduates_data) — the International Graduates Employment dataset.
- `SVD Assignment.docx` — original assignment instructions (not tracked in git).
- `script.md` — narration script for the video presentation (not tracked in git).
